# Developer & Infrastructure Cheat Sheets

This project is a compact reference hub for common developer and infrastructure tools. It brings practical commands, shortcuts, configuration notes, and workflows together in one static site for quick lookup.

The library covers:

- **Terraform:** CLI commands, plan review, state, workspaces, and configuration hygiene.
- **VS Code:** Keyboard shortcuts, editing and navigation, and useful settings.
- **Git & GitHub:** Everyday Git commands, branch workflows, GitHub Flow, and recovery guidance.
- **Okta integrations:** SAML, OIDC, and SCIM concepts, setup checklists, and troubleshooting notes.

The landing page is built with HTML and CSS, and each topic is maintained as a Markdown guide with links to official documentation sources.
